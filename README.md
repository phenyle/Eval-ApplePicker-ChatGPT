# Apple Picker OpenAI Integration

This repository the OOP and ECS versions of the apple dropping feature from Apple Picker in the book "Introduction to Game Design, Prototyping, and Development: From Concept to Playable Game with Unity and C#, 3rd Edition" by Jeremy Gibson Bond.

## Scenes

The scenes are located in the `Assets/Scenes` directory. The scenes are named as follows:

- `_Scene_0_OOP.unity`: OOP version of the scene.
- `_Scene_1_DOTS.unity`: ECS version of the scene.

## Dependencies

- [Plugin for ChatGPT / DALL-E (OpenAI)](https://assetstore.unity.com/packages/tools/behavior-ai/plugin-for-chatgpt-dall-e-openai-247238) from the Unity Asset Store.

## Testing

Tested on Unity 2022.3.13f1 on macOS 14.1.2 (Apple Silicon).

## Plotting

The plots were generated using the `plotter.ipynb` notebook. The notebook requires the following dependencies:

- `matplotlib`
- `numpy`
- `pandas`
- `scipy`
- `statsmodels`

## Data

Using the logs generated by each scene, the data can be extracted by running the following command:

```bash
grep "log:" INPUT | awk 'BEGIN { print "num_apples,fps" } { print $2 }' >OUTPUT.csv
```
